# James Medina | Marketing Portfolio

A responsive marketing portfolio built with HTML, CSS, and JavaScript for GitHub Pages.

## Included
- Professional hero section with headshot
- About and education sections
- Featured marketing and creative projects
- Einstein Bros. Bagels capstone PDF
- Marketing KPI dashboard
- Career timeline
- Skills / capabilities section
- Dark mode
- Mobile navigation
- Scroll animations
- Downloadable resume file

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository, suggested name: `james-medina-portfolio`
2. Upload the contents of this folder to the repository
3. In GitHub, open **Settings → Pages**
4. Under **Build and deployment**, choose **Deploy from a branch**
5. Select `main` and `/ (root)`
6. Save

Your site will publish to your GitHub Pages address.
